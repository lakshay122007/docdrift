# Concepts

Static analysis reads source without running it. A parser turns text into a structured form. An AST is that structure for source code. A glob matches file names. Gitignore semantics skip files using project rules. A heading slug is the URL fragment made from a heading. An exit code tells CI whether a command succeeded. CI runs checks automatically. SARIF is a JSON format for static-analysis results. A baseline hides known findings. A false positive is a finding that is not a problem. A false negative is a missed problem.
